Notes:

- All paid tiers include the same features; only the domain limit changes.

## Included with all paid tiers

- Monitor up to the tier domain limit
- Scheduled DR updates once a week
- Unlimited on-demand updates
- Email notifications
- Weekly recap email
- Backlinks & referring domains
- Milestones
- Set goals and track progress
- Leaderboard listing
- Domain directory listing
- Do-follow backlinks (2 per domain)
- No ads
